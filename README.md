# 受験票ジェネレーター

名簿（CSV / Excel）から A4 の受験票を作って印刷・PDF保存するための、ブラウザだけで動くツールです。

- 公開URL: https://toshinfuji2-beep.github.io/juken-hyo/
- ログイン: WAVE と同じアカウント（メールアドレス・パスワード）

## 使い方
1. ログインする。
2. 「デザイン（テンプレート）」を選び、項目・デザインを調整する。気に入ったら「デザインを保存」（スタッフ全員で共有されます）。
3. 「名簿」で、項目ごとに Excel の1列をコピーして貼り付ける（1行に1人）。CSV / Excelファイルや表ごと貼り付けは「その他の読み込み方法」から。
4. プレビューを確認し、「印刷 / PDF保存」を押す。

## セットアップ（初回のみ）
WAVE と同じ Supabase プロジェクトの SQL Editor で `supabase.sql` を1回実行します（共有デザイン用の `juken_presets` 表を作成します）。
実行前は「共有デザインの表がまだ作成されていません」と表示されます。

GitHub Pages: リポジトリの Settings > Pages で、ブランチのルートを公開してください（`.nojekyll` 同梱）。

## プライバシー
名簿（個人情報）はこの端末のブラウザの中だけで処理され、どこにも送信・保存されません。
共有されるのはデザイン設定（項目構成・文字・色・画像）のみです。作業中の設定の下書きはこのブラウザ内に自動保存されます。

## デザインのファイル書き出し・読み込み
「保存済みデザイン」から `.juken.json` として書き出し／読み込み（ファイル選択・ドラッグ＆ドロップ・JSON貼り付け）ができます。形式は `DESIGN_FORMAT.md`、見本は `designs/` を参照してください。

## ファイル保管

画面上部の「ファイル」から、受験票PDF・画像素材・資料をスタッフ間で保管・共有できます（ログインしたスタッフ全員が閲覧・編集・削除可能）。

- 初回のみ Supabase の SQL Editor で `supabase-files.sql` を実行（非公開バケット `juken-files` と一覧表 `juken_files` を作成。実行済み）
- 「PDFを保存」で選択中の生徒の受験票をPDF化して保管。**PDFには生徒の氏名などの個人情報が含まれ、スタッフ全員が閲覧できます。**
- デザインの画像欄の「素材から選ぶ／素材に追加」で、保管した画像を地図・ロゴに使えます
- 容量の目安：Supabase無料枠で全体1GB、1ファイル50MBまで
